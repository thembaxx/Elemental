# Elemental

**Explore the elements.**

Explore chemical elements with interactive 3D atom models, electron configurations, periodic property heatmaps and quizzes in Elemental.

`src/brand.json` holds the public name, positioning, verified canonical origin, capabilities and limits. `npm run discovery` regenerates public overview, robots, sitemap, `/llms.txt`, its `/llm.txt` alias and `/llms-full.txt`; production builds run it automatically. The SVG source and 1200×630 social PNG live in `public/`.

Voice: clear, curious and scientifically careful. Preserve the celestial blue visual identity, use Elemental consistently, and describe atom rings as simplified models. The current 23-element subset must not be advertised as a complete 118-element reference.

Current verified public origin: `https://elemental-psi.vercel.app`. Change `url` in the brand source when the production domain changes and regenerate the files. Do not use a deployment-preview or personal-report URL as the canonical origin. The sitemap contains only the homepage and public overview.

LLM files contain public product facts and source links only. They are context documents, not crawler-permission rules or a guarantee of search ranking or AI citations.

The atom mark is shared by web, Expo, Android adaptive icons and the social card. New raster assets live in `public/`; the original starter assets remain available in `assets/`. Android foreground artwork stays within the maskable safe area.
