# Elemental

> Explore chemical elements with interactive 3D atom models, electron configurations, periodic property heatmaps and quizzes in Elemental.

The current dataset contains 23 selected elements, not detailed coverage of all 118. Bohr-style rings are simplified teaching diagrams, not literal electron paths or quantum simulations. Atomic-property values are educational reference data; use authoritative scientific sources for precision work. The app is an interactive web experience that requires JavaScript; 3D rendering also needs WebGL support.
